# ZerodhaClone
A full-stack web application inspired by Zerodha’s trading platform. This project demonstrates frontend and backend integration, user authentication, and a clean UI/UX design.
Features:
- User signup/login with validation
- Dashboard for portfolio and stock tracking
- Responsive design with React components
- Backend APIs built with Node.js and Express
- Database integration using MongoDB
- Modular, reusable components (search bar, dropdowns, buttons, etc.)
Tech Stack:
- Frontend: React, CSS, JavaScript, Bootstrap
- Backend: Node.js, Express
- Database: MongoDB
- Version Control: Git & GitHub
Purpose: This project demonstrates full-stack development skills, UI/UX refinement, and scalable component design — making it a strong portfolio project for recruiters and collaborators.
